# Against The Storm - Species Needs & Requirement Chain

An unofficial fan-made web tool for analyzing species needs and building requirements in the game **Against the Storm**.

## 🎮 About

This interactive tool helps players of **Against the Storm** make informed decisions when selecting species for their settlements. By selecting any three species, players can instantly see:

- Individual needs for each species (Complex Food, Clothing, Services)
- Shared needs across all three species
- Pairwise shared needs (what any 2 species have in common)
- Detailed building requirements and ingredient chains needed to fulfill those needs

## ✨ Features

- **Interactive Species Selection**: Choose from all available species (Humans, Beavers, Lizards, Harpies, Foxes, Frogs, and Bats)
- **Shared Needs Analysis**: Instantly see which needs all three selected species have in common
- **Pairwise Comparison**: Discover needs shared by any two species in your selection
- **Building Requirements**: Get detailed information about which buildings can produce each need
- **Ingredient Chains**: See the complete production chain, including secondary ingredients
- **Star Ratings**: Buildings are displayed with their efficiency star ratings (1-3 stars)
- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Dark Mode Support**: Automatic dark mode based on system preferences
- **Visual Icons**: Game-accurate icons for species and goods

## 🚀 Usage

1. Open `index.html` in a web browser
2. Select exactly 3 species from the grid
3. View the results:
   - Individual needs for each species
   - Shared needs across all three
   - Pairwise shared needs
   - Complete building requirements and production chains

### Running Locally

Simply clone the repository and open the `index.html` file in your browser:

```bash
git clone https://github.com/Cazz0r/AgainstTheStorm.git
cd AgainstTheStorm
# Open index.html in your browser
```

No build process or dependencies required - this is a static HTML/CSS/JavaScript application.
